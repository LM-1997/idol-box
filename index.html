06

导出成品

按顺序导出：工程文件 → 分配表格 → 字幕文件。

导出工程文件

保存 .idol.json，下次可继续编辑

工程文件包含全部歌词、成员、分配信息和注音数据。保存后下次打开即可继续编辑，无需重新导入。

文件格式：.idol.json  |  包含：歌词 · 成员 · 分配 · 注音 · 播放设置
确认已保存工程文件后，继续导出分配表格
导出分配表格

导出 Excel 分配表，用于打印或存档

导出包含行号、时间、歌词和成员列的 Excel 表格。可用于打印、团队分发或线下填写。

格式：.xlsx  |  列：行号 · 时间 · 歌词 · 成员 · 备注
确认分配表无误后，继续导出字幕文件
导出成品字幕

选择格式，导出成品字幕文件

选择字幕格式并导出。导出的字幕已包含成员分配信息和当前显示设置。

07

压制成品 MV

将字幕嵌入视频，生成带字幕的成品 MV。

下载安装小丸工具箱

仅 Windows 用户需要；Mac / Linux 用户可跳过此步

小丸工具箱是一款简单易用的视频压制工具，适合不熟悉命令行的用户。下载后双击安装即可。

下载地址：https://maruko.appinn.me/（也可从其他可靠渠道获取）

Mac / Linux 用户可跳过此步骤，后续步骤中会提供 ffmpeg 命令行替代方案。

安装完成后，下一步将下载压制所需的字幕文件
下载压制用字幕

下载 ASS 字幕文件，已包含所有设置

点击下方按钮下载 ASS 字幕文件。字幕已包含你设置的成员颜色、字幕位置和延迟信息，无需额外调整。

确认字幕设置无误，准备好 MV 和字幕文件后开始压制
拖入文件并开始压制

打开小丸工具箱，拖入 MV 和字幕文件

1. 打开小丸工具箱，选择「压制」功能
2. 将你的 MV 视频文件拖入「视频」栏
3. 将刚下载的字幕文件拖入「字幕」栏
4. 点击「开始压制」按钮，等待进度条走完

备选方案（Mac / Linux 用户）：在终端中进入 MV 和字幕所在文件夹，执行以下 ffmpeg 命令完成压制。

确认压制已成功完成，将在输出目录找到成品
完成！

在输出目录找到成品 MV

压制完成！在 MV 文件所在的文件夹中可以找到带字幕的成品 MV。现在你可以将成品分享给团队成员，或用于舞台演出。祝演出顺利！
